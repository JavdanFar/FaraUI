# Changelog

All notable changes to FaraUI are documented in this file.

## [0.1.0] - 2026-09-19

### Added

- Initial preview release of the RTL-first React component library.
- Form controls, overlays, navigation, feedback, data display, and layout
  components.
- Jalali `DatePicker`, `DateRangePicker`, and `TimePicker` components.
- Public TypeScript declarations and ESM/CommonJS package outputs.
- Bundled stylesheet and stable `data-fara-*` styling hooks.
- Persian and English README documentation.

### Notes

- React 19 and ReactDOM 19 are supported.
- Browser-dependent and portal-based components should be rendered on the
  client in SSR applications.
- This is a preview release; public APIs may change before `1.0.0`.

# تغییرات

تمامی تغییرات مهم FaraUI در این فایل ثبت می‌شوند.

## [0.1.0] - ۱۴۰۵/۰۶/۲۸

### اضافه‌شده

- اولین نسخه آزمایشی کتابخانه کامپوننت‌های React با پشتیبانی از RTL.
- کامپوننت‌های فرم، overlay، ناوبری، بازخورد، نمایش داده و layout.
- کامپوننت‌های جلالی `DatePicker`، `DateRangePicker` و `TimePicker`.
- declarationهای عمومی TypeScript و خروجی‌های ESM/CommonJS.
- stylesheet تجمیع‌شده و hookهای پایدار `data-fara-*` برای سفارشی‌سازی استایل.
- مستندات فارسی و انگلیسی در README.

### نکات

- نسخه‌های React 19 و ReactDOM 19 پشتیبانی می‌شوند.
- کامپوننت‌های وابسته به مرورگر و portal باید در اپلیکیشن‌های SSR در سمت
  client رندر شوند.
- این نسخه آزمایشی است و API عمومی ممکن است قبل از نسخه `1.0.0` تغییر کند.
